## 1. 改造原则

- **不动主题层**：保留 `css/cockpit-theme.css`、`css/dashboard-design-system.css`、`css/decision-layer.css`、`js/nf-map.js`、`js/decision-layer.js`、`data/nanfeng-map.js`、`fonts/*` 与 ECharts 资源。新增样式全部写在 `pest_dashboard.html` 的 `<style>` 块里，复用现有 token（`--ck-accent-cyan`、`--ck-font-num` 等）。
- **数据真源收紧**：`alertDataSource` 保留为唯一真源，所有屏面数字 / 表格 / 排行 / 折线图 / 地图标注全部由它派生。新增字段（识别次数、设备运行、今日待办）作为 `alertDataSource` 的新字段，不重新建数据源。
- **结构遵循参考图骨架**：
  ```
  顶刊头（Logo+标题+日期 + Slogan）
  ─────────────────────────────────────
  KPI 单行 6 张
  ───────────┬─────────────┬───────────
  左栏       │ 中栏（地图） │ 右栏
  ───────────┴─────────────┴───────────
  底部三栏（环形 + 趋势 + 待办）
  ```
- **保留可点击行为**：KPI 卡 → `openModal`；地图气泡点击 → `openModal`；监测点浮卡 → 详情。
- **不动 GIS 边界**：南丰县 GeoJSON 已覆盖 12 个乡镇，参考图中点位/排名必须落在真源乡镇内。
