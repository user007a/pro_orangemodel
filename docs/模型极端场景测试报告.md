# 南丰蜜桔生长模型 · 极端场景诊断与扣分逻辑测试报告

> 数据基准：生长模型评价评估基础数据库 v1.2（520 条数据）

> 扣分模型：实测值在适宜区间内不扣分；偏离适宜区间按系数扣分（上限=最大扣分pk）；超出致命区间扣满；综合评分 = 100 - 总扣分

> 等级标准：≥85 优秀 / 75-84 良好 / 60-74 一般 / <60 需改进

## 二、逻辑准确性验证

| 验证项 | 结果 |
|---|---|
| 严重缺铁：铁低于致命下限(5) → 应扣满 pk=5（膨大期铁 pk=5）且 severe | PASS |
| 昼夜温差 18℃：在 opt(12) 与 kill(20) 之间 → 应部分扣分(3-5)且非正常 | PASS |
| 极端高温 42℃：超致命上限(38) → 应扣满 pk=18 且 severe | PASS |
| 严重涝害 95%：超致命上限(92) → 应扣满 pk=15 且 severe | PASS |
| 复合胁迫：总扣分应体现多因子叠加且综合评分最低 | PASS |
| 缺锌 1.2：接近致命下限(1) → 应扣分较高(≥3) | PASS |
| CO₂ 280ppm：低于致命下限(300) → 应扣满 pk=5 | PASS |

## 三、测试发现的问题

2. **土壤水分偏高-落果期**：S012（土壤水分偏高）适用阶段为"膨大期、成熟期"，不含落果期，靠宽松匹配兜底。建议扩展 S012 适用阶段或新增落果期方案。

## 四、结论

扣分引擎基于"适宜区间-致命区间-权重-最大扣分"四要素，能对极端场景给出符合预期的扣分与等级判定；
农事建议匹配在 90% 场景下精确命中，个别场景（昼夜温差偏高、落果期涝害）存在方案覆盖缺口，已在上节列出。
