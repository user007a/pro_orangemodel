# 南丰蜜桔生长模型管理 - 产品需求文档

## 概述
- **摘要**: 在南丰蜜桔模型管理系统后台新增一级菜单「生长模型」，位于「模型管理」与「数据管理」之间，实现从基础档案录入到评价报告生成的完整业务闭环。该模块基于《南丰蜜桔生长-环境-品质统一模型》算法文档，覆盖静态参数配置、动态因子采集、模型引擎计算（适宜度/门控/生长增量/扣分/综合评分）、智能诊断推理、农事策略匹配、多维度可视化评价、PDF/网页报告生成全流程。
- **目的**: 将生长模型的核心算法、数据、诊断、建议、报告等功能系统化落地，为农技人员提供可操作、可追溯、可校准的数字化管理工具。
- **目标用户**: 南丰县蜜桔产业农技管理员、数据运维人员、蜜桔合作社技术人员。

## 目标
- 新增一级菜单「生长模型」及其子菜单导航
- 实现5大数据库（静态基础库、动态因子库、模型状态库、诊断知识库、报告结果库）的前端管理界面
- 实现模型计算引擎前端交互（单因子适宜度S(x)、温湿度门控Gth、综合环境E、生长迭代、六维度扣分、品质预测）
- 实现诊断推理引擎前端交互（扣分溯源、因果链展示、风险分级）
- 实现农事方案匹配引擎前端交互（按阶段/胁迫匹配方案、优先级排序、复查指标）
- 实现自动评价报告生成与预览（网页预览+PDF导出）
- 实现数据校准模块（历史实测数据对比、参数微调）

## 非目标（不在范围内）
- 不涉及后端实际服务端代码（仅前端静态HTML原型）
- 不涉及物联网设备真实对接（使用模拟数据）
- 不涉及农户APP移动端开发
- 不涉及大数据指挥GIS大屏开发
- 不涉及实际PDF生成后端服务（前端模拟预览展示）

## 背景与上下文
- 现有系统已包含「模型管理」一级菜单，下辖「生长模型说明」和「病虫害模型说明」两个子菜单
- 本次需将「生长模型说明」从「模型管理」下迁移至新的一级菜单「生长模型」下，并扩展完整的业务子模块
- 核心算法来源：`docs/生长模型-算法过程.md`
- 技术栈：Tailwind CSS + Chart.js + 原生HTML/JS

## 功能需求

### FR-1: 菜单导航
在侧边栏新增一级菜单「生长模型」，位于「模型管理」之后、「数据管理」之前。包含以下子菜单：
- 基础档案（品系管理、地块档案、阶段参数）
- 因子采集（物联网实时数据、人工采样录入、农事操作记录）
- 模型计算（计算调度中心、手动计算、计算日志）
- 诊断分析（扣分溯源、原因链、农事建议）
- 评价报告（报告预览、报告导出、历史报告）
- 数据校准（物候数据对比、参数微调）

### FR-2: 基础档案管理
实现静态参数配置页面：
- **品系管理**: 品系列表（品系名称、砧木修正系数、树龄修正系数、特征备注），支持新增/编辑/删除
- **地块档案**: 地块列表（对象编码、品系、砧木、树龄、面积、海拔、坡度、栽培方式、负责人），支持CRUD
- **阶段参数**: 6个生育阶段（幼苗/生长/开花/落果/膨大/成熟）的因子阈值配置，每阶段支持温度/湿度/土壤水/光照/钾/PH等因子的最适区间、致命阈值、权重、最大扣分值配置

### FR-3: 因子数据采集
实现多渠道因子录入：
- **物联网实时数据**: 展示设备自动采集的实时数据列表（温度、湿度、土壤水、光照、降雨），模拟自动刷新
- **人工采样录入**: 定期采样表单（果径、糖度、SPAD、土壤PH/EC、氮磷钾、挂果量），支持单条录入和Excel批量导入
- **农事操作记录**: 农事记录列表（灌溉/施肥/疏果/修剪/遮阳/打药/排水），支持新增和查询

### FR-4: 模型计算中心
实现模型引擎调度与执行：
- **计算调度**: 定时任务配置（每日凌晨2点自动批量计算），支持手动触发
- **计算日志**: 展示每次计算的地块数、成功/失败数、耗时、异常信息
- **手动计算**: 选择地块+日期，一键重新运行全套模型（S(x)→Gth→E→生长迭代→扣分→评分→诊断→建议→预测）

### FR-5: 诊断分析
实现智能诊断推理展示：
- **综合评分面板**: 单地块综合总分、健康等级、六大维度分项得分雷达图
- **扣分溯源**: 每条扣分明细（因子、实测值、适宜区间、扣分值、偏离程度）
- **原因链**: 扣分对应的多级因果推理（现象→直接原因→深层诱因）
- **农事建议**: 按优先级排序的农事处置方案、复查周期、复查监测指标
- **品质预测**: 果径、果重、糖度、糖酸比、预估亩产、商品果率、预测置信度

### FR-6: 评价报告
实现自动报告生成与导出：
- **报告结构**: 基础信息→综合结论→六维度得分表→扣分明细→风险诊断→农事建议→品质预测→风险提示→数据可信度
- **在线预览**: 完整报告网页预览
- **导出PDF**: 模拟PDF导出（前端打印/下载）
- **历史报告**: 历史报告列表查询、查看、删除

### FR-7: 数据校准
实现模型精度校准：
- 历史实测数据（物候、采收数据）与模型预测值对比
- 误差分析图表
- 参数微调入口（修改权重、生长系数）

## 非功能需求
- **NFR-1**: 所有页面风格与现有系统一致（Tailwind CSS、配色、布局结构）
- **NFR-2**: 响应式设计，适配主流PC屏幕（1280px+）
- **NFR-3**: Mock数据必须贴合南丰蜜桔实际生产场景
- **NFR-4**: 交互流畅，图表渲染无明显卡顿

## 约束
- **技术**: 使用现有技术栈（Tailwind CSS CDN、Chart.js CDN、原生HTML/JS）
- **架构**: 保持与现有index.html一致的iframe子页面加载架构
- **风格**: 与现有系统页面（如home.html、growth_model.html等）视觉风格统一

## 假设
- 所有子页面通过index.html的iframe加载机制呈现
- 模型计算、诊断推理、报告生成为前端模拟逻辑
- 物联网数据使用模拟定时刷新数据
- PDF导出通过浏览器打印或前端HTML转PDF实现

## 验收标准

### AC-1: 菜单正确渲染
- **Given**: 用户登录系统后
- **When**: 查看侧边栏菜单
- **Then**: 「生长模型」一级菜单出现在「模型管理」之后、「数据管理」之前，展开后显示6个子菜单
- **验证**: `programmatic`

### AC-2: 基础档案CRUD功能完整
- **Given**: 进入「基础档案」子菜单
- **When**: 切换品系管理/地块档案/阶段参数Tab
- **Then**: 各Tab显示对应数据列表，支持新增/编辑/删除操作，表单校验正确
- **验证**: `programmatic`

### AC-3: 因子采集数据录入正确
- **Given**: 进入「因子采集」子菜单
- **When**: 在物联网数据页查看实时数据、在人工采样页录入数据、在农事记录页新增记录
- **Then**: 数据正确展示、录入校验通过、列表实时更新
- **验证**: `programmatic`

### AC-4: 模型计算流程可执行
- **Given**: 进入「模型计算」子菜单
- **When**: 选择地块和日期，点击手动计算
- **Then**: 前端依次展示S(x)适宜度、Gth门控、E综合环境、生长增量、扣分、综合评分的计算过程和结果
- **验证**: `human-judgment`
- **备注**: 需展示完整计算链路和中间结果

### AC-5: 诊断分析展示完整
- **Given**: 进入「诊断分析」子菜单并选择地块/日期
- **When**: 查看诊断结果
- **Then**: 展示综合评分、六维度雷达图、扣分明细表、因果原因链、农事建议清单、品质预测数据
- **验证**: `human-judgment`

### AC-6: 评价报告生成与导出
- **Given**: 进入「评价报告」子菜单
- **When**: 选择地块+日期生成报告
- **Then**: 报告包含所有9个模块，可在线预览、可导出PDF
- **验证**: `human-judgment`

### AC-7: 视觉风格一致性
- **Given**: 所有新页面
- **When**: 对比现有系统页面风格
- **Then**: 配色、字号、组件样式、布局结构保持一致
- **验证**: `human-judgment`
