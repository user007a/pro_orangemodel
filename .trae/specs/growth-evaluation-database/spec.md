# 生长模型评价评估基础数据库 - 规格说明

## Why
生长模型菜单下的子页面（模型说明、基础档案、因子采集、农事建议、模型计算、诊断分析、评价报告、数据校准）中散落着大量与南丰蜜桔果树、果实生长相关的 Mock 基础数据，但数据分散在多个 HTML 文件中且覆盖不全，无法作为系统评价评估体系的完整结构化支撑。

## What Changes
- 生成一个 Excel 文件 `生长模型评价评估基础数据库.xlsx`，放置于 `d:\dev\pro_orangemodel\docs\` 目录
- **以现有 Mock 数据为骨架**，系统性梳理并扩充为更全面、更丰富的评价评估基础数据库：
  - Mock 已有数据 → 完整保留并逐字落表
  - Mock 缺失但评价体系需要 → 基于南丰蜜桔/柑橘领域科学常识补充（标注【科学补充】）
- 按主题拆分多个工作表（Sheet），全部结构化落表
- **不改动任何代码文件**，仅新增 Excel 文件

## Impact
- 受影响规格：无（新产物）
- 受影响代码：无（只读 HTML 提取数据）
- 输出文件：`d:\dev\pro_orangemodel\docs\生长模型评价评估基础数据库.xlsx`

### Requirement: 科学补充数据（比 Mock 更全面丰富）
系统 SHALL 在 Mock 数据基础上，基于南丰蜜桔/柑橘领域知识系统补充评价评估所需数据，补充行在"数据来源"列标注【科学补充】。重点补充方向：

#### 品种品系
- 南丰蜜桔主栽良种：杨小-26（最著名品种，果实小、皮薄、味香甜）、早蜜、蜜广、小果系等
- 砧木类型：枳壳、红桔、酸橙、枳橙、香橙等及各自特性

#### 生育阶段（物候期）
- 将 6 大阶段细分为南丰地区完整物候期：萌芽期、春梢生长期、现蕾期、初花期、盛花期、第一次生理落果期、第二次生理落果期、夏梢生长期、果实膨大期、果实着色期、成熟采收期、花芽分化期（秋冬）
- 标注各阶段大致时间范围（如萌芽期 3月上旬、膨大期 7-8月、成熟期 11-12月）

#### 因子与指标
- 补充营养因子：有机质、钙、镁、铁、锌、硼、钼等中微量元素
- 补充环境因子：CO₂浓度、风速、蒸发量、昼夜温差
- 补充果实品质指标：维生素C、总酸、糖酸比、可食率、出汁率、果皮厚度、单果重、横纵径比

#### 农事建议库
- 补充极端天气场景：冻害预警、暴雨涝害、大风倒伏、高温日灼、干旱胁迫
- 补充缺素症场景：缺氮/缺磷/缺钾/缺钙/缺镁/缺硼/缺锌
- 补充花果管理：保花保果、疏花疏果、环割促花

#### 病虫害库
- 检疫性/重要病害：柑橘黄龙病、溃疡病、疮痂病、炭疽病、脚腐病、流胶病/树脂病、黑斑病、青苔病
- 重要虫害：柑橘全爪螨(红蜘蛛)、锈壁虱、潜叶蛾、柑橘木虱、蚜虫、粉虱、蚧壳虫、天牛、实蝇、蓟马、花蕾蛆
- 每条含：危害部位、症状特征、发生规律、防治要点

#### 农药方案
- 补充常用农药：阿维菌素、吡虫啉、代森锰锌、多菌灵、毒死蜱、螺螨酯、联苯肼酯、矿物油、波尔多液等
- 含稀释倍数、防治对象、安全间隔期

#### Scenario: 补充可追溯
- **WHEN** 查看补充数据行
- **THEN** 能通过"数据来源"列标注【科学补充】区分 Mock 数据与补充数据
