## 1. 改造原则

- **不动主题层**：保留 `css/cockpit-theme.css`、`css/dashboard-design-system.css`、`css/decision-layer.css`、`js/nf-map.js`、`js/decision-layer.js`、`fonts/*` 与 ECharts 资源；新增样式全部写在 `growth_dashboard.html` 的 `<style>` 块里，复用现有 token（`--ck-accent-cyan`、`--ck-font-num` 等）。
- **数据真源收紧**：`growthDataSource` 保留为唯一真源，所有屏面数字 / 表格 / 排行 / 柱图 / 地图标注全部由它派生（与现状一致），避免出现"同一乡镇两个分数"。
- **图表替换**：
  - 原综合评价子项 `qualityTrendChart` → 改为 `riskReasonBar`（横向条形 TOP5）
  - 新增 `farmingSuggestionChart`（农事决策建议柱状图）
  - 预警处理情况采用卡片式 4 宫格（沿用 cockpit 卡片样式）
- **结构遵循现有骨架**：外层 `.dashboard-container`、三栏 `.map-core-grid > .side-col / .center-map-card / .side-col`、底部两栏；不再引入新的栅格系统，避免响应式回归。
- **逐块保留可点击行为**：地图气泡点击 → `openModal`；KPI 卡 → `openModal`；重点关注基地行点击可高亮对应乡镇（在地图上）。
