# 农事建议配置管理 - 产品需求文档

## 概述
- **摘要**: 创建一个独立的农事建议配置管理页面，用于可视化管理农事建议数据库（`farmSchemeDB`），支持因子与建议的增删改查和关联配置。
- **目的**: 解决当前农事建议硬编码在 `diagnosis.html` 中的问题，提供一个可维护、可扩展的配置管理界面，让管理员可以根据实际需要动态调整农事建议方案。
- **目标用户**: 农技管理员、系统配置人员

## 目标
- 提供农事建议方案的完整 CRUD 功能
- 实现因子-建议关联的可视化配置
- 支持按因子类型、优先级、生育阶段等多维度筛选
- 提供方案预览功能，可测试扣分项触发的建议

## 非目标
- 不实现后端 API 对接（当前为前端 Mock 数据）
- 不实现用户权限管理
- 不涉及农事建议的实际执行流程

## 背景与上下文
- 当前 `diagnosis.html` 已实现农事建议数据库和匹配引擎，但数据硬编码在 JS 中
- 需要将数据库管理功能独立出来，提供可视化配置界面
- 菜单结构：生长模型 > 农事建议配置（新增）

## 功能需求

### FR-1: 农事建议方案管理
- 支持查看所有农事建议方案列表
- 支持按因子类型、优先级、生育阶段、偏离方向筛选
- 支持新增农事建议方案
- 支持编辑已有农事建议方案
- 支持删除农事建议方案（带确认提示）

### FR-2: 方案详情配置
每条农事建议方案包含以下可配置字段：
- 方案 ID（自动生成）
- 因子类型（关联扣分项因子）
- 偏离方向（偏高/偏低/失调）
- 适用生育阶段（多选：幼苗期/生长期/开花期/落果期/膨大期/成熟期）
- 优先级（urgent/important/normal/low）
- 详细措施列表（多条，有序）
- 复查周期
- 复查监测指标
- 预期调节效果

### FR-3: 因子映射管理
- 查看当前所有因子映射关系（`factorMapping`）
- 支持新增因子映射（因子名 → 建议类型）
- 支持编辑因子映射
- 支持删除因子映射

### FR-4: 方案预览/测试
- 提供测试工具，可输入模拟扣分项
- 预览该扣分项会触发哪些农事建议
- 验证匹配逻辑是否正确

### FR-5: 数据持久化（前端模拟）
- 使用 localStorage 保存配置数据
- 页面刷新后数据不丢失
- 提供"恢复默认数据"功能

## 非功能需求
- **NFR-1**: 页面加载时间 < 2秒
- **NFR-2**: 支持主流浏览器（Chrome、Edge、Firefox）
- **NFR-3**: UI 风格与现有系统保持一致（Tailwind CSS）
- **NFR-4**: 响应式设计，支持最小 1280px 宽度

## 约束
- **技术**: 纯前端实现，使用 Tailwind CSS + 原生 JavaScript
- **业务**: 数据结构需与 `diagnosis.html` 中的 `farmSchemeDB` 保持一致
- **依赖**: 复用 `diagnosis.html` 中的匹配引擎逻辑

## 假设
- 用户了解农事模型和因子扣分机制
- 因子名称与扣分项保持一致
- 当前为单机使用，无需多用户协作

## 验收标准

### AC-1: 方案列表展示
- **Given**: 用户打开农事建议配置页面
- **When**: 页面加载完成
- **Then**: 显示所有农事建议方案列表，包含方案ID、因子类型、优先级、适用阶段、措施摘要
- **验证**: `human-judgment`
- **备注**: 列表支持分页或滚动浏览

### AC-2: 新增农事建议方案
- **Given**: 用户点击"新增方案"按钮
- **When**: 填写完整表单并提交
- **Then**: 新方案添加到列表，显示成功提示，可在诊断分析页面匹配到
- **验证**: `programmatic`

### AC-3: 编辑农事建议方案
- **Given**: 用户点击某条方案的"编辑"按钮
- **When**: 修改字段并保存
- **Then**: 方案更新成功，列表显示最新数据
- **验证**: `programmatic`

### AC-4: 删除农事建议方案
- **Given**: 用户点击某条方案的"删除"按钮
- **When**: 确认删除
- **Then**: 方案从列表移除，显示删除成功提示
- **验证**: `programmatic`

### AC-5: 筛选功能
- **Given**: 用户设置筛选条件（因子类型/优先级/阶段）
- **When**: 点击筛选或实时筛选
- **Then**: 列表只显示符合条件的方案
- **验证**: `programmatic`

### AC-6: 方案测试
- **Given**: 用户在测试区输入模拟扣分项
- **When**: 点击"测试匹配"
- **Then**: 显示匹配到的农事建议列表
- **验证**: `programmatic`

### AC-7: 数据持久化
- **Given**: 用户修改并保存配置
- **When**: 刷新页面
- **Then**: 数据保持不变
- **验证**: `programmatic`

### AC-8: 因子映射管理
- **Given**: 用户访问因子映射Tab
- **When**: 进行增删改操作
- **Then**: 映射关系正确更新
- **验证**: `programmatic`
