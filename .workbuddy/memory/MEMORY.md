# 项目长期记忆 · pro_orangemodel（南丰蜜桔全产业链大数据平台）

## 项目结构约定
- `html/dataanlye/` — 分析大屏（生长模型、病虫害模型两张驾驶舱）
- `html/` — 原型页面（69 个 HTML）
- `docs/` — 需求规格文档
- 交付后习惯：拿原型与大屏交叉对照，检查是否有遗漏页面或设计项

## 大屏（html/dataanlye）设计规范 —— 修改前必读
- **主题**：深色驾驶舱，底色 `#050d1a`，主色青 `#00d4ff`，token 集中在 `css/cockpit-theme.css`（`--ck-*`）
- **字体 token 单一来源**：`css/fonts.css`
  - `--ck-font-family` = 自托管 Noto Sans SC（中文）
  - `--ck-font-num` = 自托管 Barlow Condensed（数字/KPI），**不要再用 'DIN Alternate'**
  - 字体文件在 `fonts/`，离线可用；数字统一 `tabular-nums`
- **地图**：`data/nanfeng-map.js`（真实边界）+ `js/nf-map.js`（共用渲染模块），两张大屏共用，**不要各自内联一份地图配置**
  - 单一青色 5 级色阶 `#123A6E → #16528F → #1E7FB8 → #35B4DE → #5AD7F0`，深浅表达数值
  - 无数据区（长红垦殖场、南丰工业园区）用中性灰 `#3F4A5C` + 虚线边
  - 全局发光只允许出现在「告警/选中」标注点
  - 禁止：3D 投影层、扫描圈、扫描线、红黄绿热力色
- **图表配色规则**：连续型数值（评分/条数/占比）用 `NFMap.rampByRank(values)` 单色相按排名取色；
  红/橙/黄只用于状态语义（预警级别、告警）
- **大屏可读性**：字号下限 12px（`--ck-text-xs`），KPI 32px+，正文 14px
- **文字对比度**：正文≥4.5:1（WCAG AA）；`--ck-text-muted` 已定为 `#94a3b8`
- **颜色替换注意**：不要用全文字符串替换改色，会破坏 `--bg-white`、`white-space` 这类标识符

## 大屏业务表达规范 —— 新增指标/面板前必读
> 背景：大屏视觉达标后，从农业农村局视角评审发现「表达不准确」。以下原则已落地，**后续改造不得回退**。

- **数据口径单一真源**：KPI、表格、图表数字一律从 JS 数据源派生，**禁止在 HTML 里另写一套数字**
  - pest：`alertDataSource.alertByType`（类型 × 红橙黄蓝 矩阵）为唯一真源，`levels` 为其列合计口径
  - 内置 `assertAlertMatrix()` 自校验，控制台报错；`verify-dashboards.mjs` 有对应硬校验
- **⚠️ 删/改数据源字段后必须跑校验脚本**（血泪教训）：
  删掉 `alertDataSource.types` 后，`renderModalStats` 里残留 5 处 `alertDataSource.types.*`，
  JS 语法检查完全合法，但该字面量求值时抛 TypeError → `renderModalDetails` 不再执行 →
  **8 个 KPI 弹窗的「核心指标 / 详情数据」全空，而 ECharts 图表照常渲染**，肉眼极易漏掉。
  现有三道防线：①引用键 ⊆ 定义键 ②每个 `openModal` 入口在 stats/details 均有配置
  ③在 vm 沙箱里真实执行渲染函数查空/查抛错。**改完数据源务必执行 `verify-dashboards.mjs`。**
- **KPI 只放动态业务指标**：禁止放「静态常量」（如病害种类数=知识库条目数）与「纯算法指标」
  （如图像识别准确率）；这两类应降级为副指标或运维视图
- **连续型数值 vs 状态语义**：同前（见「图表配色规则」）
- **样本代表性必须写清楚**：数字旁标注样本量；样本 <3 标注「仅供参考」；
  无监测点的区域**不得给评分**（用 `value:-1` 走灰色 + tooltip 说明）
- **大屏要有结论**：每屏顶部一句话播报（`.ck-brief`）；关键短板要显性成文，不能只体现在柱子高度上
- **口径诚实**：「全县平均」这类措辞必须与样本口径一致（现为「监测样本均值 n=26」）
- **责任闭环**：预警/建议需带责任人 + 完成时限，不能只有「建议」
- **阈值参照**：环境/气象数值必须给适宜区间（`growthDataSource.envRanges`），否则数字无判断价值

## 病虫害业务要点（业务方关注）
- **黄龙病是柑橘毁灭性检疫病害、一号防控对象**，必须独立常驻监测，不能混在普通病害列表里；
  其媒介**柑桔木虱**的权重不可按普通虫害评「轻度」
- 防控四问：**发生多少 / 防了多少 / 效果如何 / 损失多少**
  （发生面积、防治面积、防治效果、挽回损失；另含绿色防控覆盖率、统防统治、农药减量）
- 在田发生面积按种类归因时**每块地只归因一个主要种类**，保证分项之和 = 总面积，不重复计算

## 常用命令
- 两张大屏回归检查：`node html/dataanlye/verify-dashboards.mjs`
  （遗留浅色值 / CSS 合法性 / JS 语法 / 地图数据完整性 / **数据口径一致性** /
  **数据源引用完整性** / **弹窗数据完整性 + 沙箱渲染实测**）
- 无头截图：`msedge.exe --headless=new --disable-gpu --hide-scrollbars --window-size=1920,1080 --virtual-time-budget=20000 --screenshot=out.png <file-url>`

## 环境限制（本机）
- Bash 工具不可用（shell shim 缺 `dirname`），统一用 PowerShell
- PowerShell stdout 不回显，结果需写入文件后读取
- PowerShell 5.1 不支持 `(if (){}else{})` 作为表达式，会 exit 1
- **无头截图连续调用同一浏览器必然第二次失败**（Edge/Chrome 均如此，疑似复用已运行实例）；
  页面有入场动画时截图会早于动画完成 —— 需生成「禁动画副本」再截，或直接用校验脚本验证
- 不要杀 Chrome/Edge 进程 —— 用户可能正在浏览器里看这些页面
